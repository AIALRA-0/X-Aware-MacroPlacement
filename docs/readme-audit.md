## 6 风险边界

- 当前相对热场不是物理温度，也没有误差界
- PLC 轻量解析器把 1410 条有效坐标记录都视为宏，与注释中的 133 个硬宏不是同一统计口径
- 仓库缺少依赖清单、自动化测试和持续集成
- CLI 与 GUI 复制了输入和功耗辅助逻辑，后续可能产生行为漂移
- `--save-npy` 不跟随 `--out-dir`，可能写入根目录数据资产
- `external/` 包含多个许可证、大型基准和二进制产物，分发时需要逐层审查
